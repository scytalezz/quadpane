# v0.8.0 표시·선택·이동 개선

v0.8.0에 포함되는 변경 사항입니다(소스 기준 2026-10-14). [v0.8.0 릴리스 노트](releases/v0.8.0.md)와 함께 읽으세요. 아래 프리뷰 검증 기록은 기존 v0.7.0 배포 파일 및 새 v0.8.0 배포 EXE의 검증과 구분합니다.

## 표시 설정

도구 모음의 **보기**에서 **숨김 항목**과 **파일 확장자**를 각각 선택합니다. 기본값은 숨김 항목 끄기, 확장자 켜기입니다. 모든 패널과 두 작업 공간에 공통 적용하며 `quadpane-data/preferences.json`에 저장합니다. 기존 즐겨찾기·최근 경로 설정은 그대로 읽고 누락된 표시 설정만 기본값으로 처리합니다.

Windows의 Hidden 속성을 읽습니다. 파일명이 점으로 시작한다는 이유만으로 숨기지 않습니다. 조회 중 사라졌거나 속성을 읽지 못한 항목은 해당 항목만 제외하고 목록에 제외 개수를 알립니다. 속성 조회 프로세스 전체가 실패하면 오류를 표시하며 임의로 모든 항목을 노출하지 않습니다.

확장자 숨기기는 목록의 일반 파일 이름에만 적용합니다. 실제 경로, 파일 아이콘, 검색, 이름 변경 입력과 파일 정보는 전체 파일명을 사용합니다. 폴더 이름과 점으로 시작하는 파일 이름은 유지합니다. 숨겨진 항목은 전체 선택과 파일 작업 대상에서 제외합니다.

## 드래그 선택

- 목록 아래 빈 공간이나 양옆 여백에서 왼쪽 버튼을 누르고 드래그합니다.
- 사각형과 겹치는 파일·폴더가 선택됩니다. `Ctrl` 또는 `Shift`를 누르면 기존 선택에 추가합니다.
- 위·아래 가장자리에서 드래그를 유지하면 목록을 자동으로 스크롤합니다.
- `Escape`, 포인터 취소, 창 포커스 상실 시 이전 선택으로 복원합니다. 폴더·화면 분할 변경 시에도 선택 드래그를 정리합니다.
- 파일 행에서 시작하는 드래그는 기존 Windows 파일 끌어 놓기로 동작합니다.

## 이동 안정성 개선

- **이동 후 클립보드 오류:** 파일이 이미 이동한 뒤 클립보드 완료 알림이 실패하더라도 실제 완료 결과를 유지하고 양쪽 폴더를 새로 읽습니다. 클립보드 경고는 별도로 표시합니다.
- **상위·하위 항목 중복 요청:** 상위 폴더에 포함된 항목을 따로 처리하지 않아 선택 순서에 따라 중복 복사되거나 원본 없음 오류가 발생하지 않습니다. 상위 폴더와 함께 이동된 하위 항목도 클립보드 완료 목록에서 정리합니다.
- **대소문자만 바꾸는 이름 변경:** 중간 이동 응답을 잃었을 때 파일이 그대로 있다고 가정하지 않습니다. 원본의 동일성과 대상 존재 여부를 확인하고 안전한 경우에만 되돌립니다. 결과가 불확실하면 확인할 경로를 안내합니다.
- **오류 정보:** 네트워크 연결·드라이브·사용 중인 파일 오류를 구분하며, 부분 이동에서는 원인 코드와 남은 위치 정보를 보존합니다. 불확실한 이동을 자동 재시도하거나 남은 파일을 임의로 삭제하지 않습니다.

## 소스 검증

자동 테스트와 실제 Windows 패키징 앱을 사용합니다. 파일 작업은 별도 테스트 폴더만 변경하며, 사용자 클립보드와 외부 앱 드래그 호출은 통합 검사에서 대체합니다.

- 문법 검사: JavaScript 32개 파일 통과.
- 자동 테스트: **145개 통과, 실패·건너뜀 없음**. `PANE_TEST_CROSS_VOLUME_DIR`에 C: 드라이브의 테스트 전용 디렉터리를 지정했습니다. D:→C: 파일·폴더 이동, 잠긴 파일, 일부만 이동된 폴더, 작업 중 대상 생성 충돌을 실제 테스트 파일로 확인했습니다.

최신 로컬 검사는 최종 0.8.0 버전으로 실행했습니다. 다른 드라이브 간 이동 검사에는 C: 드라이브의 테스트 전용 디렉터리를 사용했으며, 테스트 로그는 `.checks/v0.8.0-local-tests.log`입니다.

위 결과와 해시는 프리뷰에만 해당하며 새 `quadpane-0.8.0-portable-x64.exe`의 빌드·실행 검증 결과가 아닙니다. 공식 0.8.0 EXE는 Windows CI에서 생성하며 SHA-256 체크섬을 함께 제공합니다. 게시된 EXE의 런처 검증은 별도로 진행합니다. 업그레이드할 때는 기존 앱을 완전히 종료하고 기존 `quadpane-data/`를 새 EXE 옆에 그대로 둡니다.

실제 SMB 공유 장애, 외장 드라이브 분리, 사용자의 특정 오류 상황은 재현하지 않았습니다. 네트워크 오류 매핑 검사는 실제 네트워크 장애를 재현한 검사와 구분합니다.
