# 소스 검토 및 최적화 (2026-11-05)

v0.9.3 이후 작업 트리의 검토 기록입니다. 버전 변경이나 릴리스 게시를 의미하지 않습니다.

## 검토 범위

- 렌더러의 정렬·검색·선택, 탐색 및 새로고침 상태 전환
- 파일 복사·이동, 디렉터리 읽기, Windows 셸 도우미와 IPC
- 메인 프로세스의 시작·종료, preload 접근 경계
- 설정 저장, 업데이트 다운로드·검증, 작업 표시줄 연동
- 개발 서버, 네이티브 빌드 및 배포 설정

## 반영한 변경

- 동일한 디렉터리 스냅샷의 정렬 결과를 재사용하고 한국어 정렬 비교기를 재사용합니다. 목록 교체, 검색어, 숨김 표시, 정렬 기준·방향이 바뀌면 다시 계산합니다. 파일 시스템 조회 결과 자체를 캐시하지는 않습니다.
- 여러 패널 검색 후 선택 상태 갱신을 한 번만 수행하고, 변하지 않은 행의 접근성 속성 쓰기를 줄입니다.
- 새로고침 응답 대기 중 사용자가 바꾸거나 해제한 선택을 응답 완료 시점에 보존합니다.
- 대상 이름 충돌은 원본 하위 트리 검사 전에 확인합니다. 최종 파일 게시 단계의 덮어쓰기 방지는 유지합니다.
- 이동 도우미의 표준 입출력 통신 오류를 처리하고, 도우미 종료 전 작업 잠금을 해제하지 않습니다. 통신 오류가 발생한 이동을 자동 재시도하지 않습니다.
- 작업 공간 설정 저장은 고유한 임시 파일을 배타적으로 생성합니다. 기존 임시 파일에 연결된 다른 파일을 덮어쓰지 않으며, 생성에 실패한 파일을 정리 대상으로 삭제하지 않습니다.
- 로딩 검증 스크립트의 오래된 8개 패널 조회 가정을 현재의 보이는 패널만 읽는 동작에 맞췄습니다.

## 측정 및 검증

4개 패널에 각각 1,000개 항목을 둔 VM 계측에서 10회 선택 시 정렬은 10회에서 0회, 검색 입력 조회는 10,040회에서 30회, 행 속성 쓰기는 40,000회에서 19회로 줄었습니다. 검색 한 번의 선택 갱신은 4회에서 1회로 줄었습니다. 이는 작업 횟수이며 실제 화면 표시 속도의 배율을 뜻하지 않습니다.

128개 하위 파일이 있는 대상 충돌 사례에서 원본 폴더 열거 1회와 하위 파일 메타데이터 조회 128회가 모두 없어졌습니다. 복사·이동 두 경우 모두 원본과 대상의 내용이 유지되는 것을 검사했습니다.

- JavaScript 구문 검사 53개 통과
- 전체 Node 테스트 395개 통과, 2개 건너뜀, 실패 없음 (별도 드라이브 테스트 포함)
- 렌더러 최적화·선택 경합 회귀 검사 9개 통과
- 숨김 Electron 창에서 실제 임시 폴더를 사용하는 로딩·탐색 검사 5개 묶음 통과
- 헤드리스 브라우저에서 복사·붙여넣기 경합 24개, 드래그 복구 12개, 업데이트 화면 5개 묶음 통과 (IPC 응답은 격리된 테스트 데이터 사용)

건너뛴 항목은 파일 심볼릭 링크 생성 권한과 별도 SMB 공유가 필요한 검사입니다. 실제 사용자 파일이나 클립보드는 사용하지 않았습니다. 물리적 마우스로 탐색기·브라우저에 드롭하는 동작, 느린 네트워크 공유, 최종 EXE의 시작 시간은 이번 검증 대상에 포함되지 않습니다.
