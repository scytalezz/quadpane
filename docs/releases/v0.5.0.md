# Quadpane v0.5.0

Windows x64 포터블 · `0.5.0`

파일: `quadpane-0.5.0-portable-x64.exe`

## 주요 변경

- 파일·폴더·다중 선택·빈 공간에 Windows 클래식 셸 우클릭 메뉴를 제공합니다. 설치된 셸 확장을 사용하며 Windows 11 간소화 메뉴는 지원하지 않습니다.
- 기본 드래그를 네이티브 OLE 방식으로 연결해 Alt 없이 외부 앱으로 파일·폴더를 보냅니다.
- `Ctrl+C/X/V`와 셸 메뉴 복사·잘라내기를 Windows 파일 클립보드와 연동합니다.
- 포커스 복귀 시 클립보드 읽기와 메뉴·드래그 요청이 충돌하는 문제를 수정했습니다. 클립보드 작업 뒤에 메뉴·드래그 하나를 예약하고, 예약·실행 중 추가 셸 요청은 `SHELL_BUSY`로 거부합니다.
- 셸 작업 실패를 폴더 읽기 오류(`READ_FAILED`)로 잘못 표시하던 문제를 수정했습니다. 작업별 한국어 안내와 원래 오류 정보를 유지합니다.

## 제한 사항

- 외부에서 들어오는 드롭은 Shift를 눌러도 복사입니다. 외부 파일을 이동하려면 잘라내기·붙여넣기를 사용하세요.
- 외부로의 이동은 대상이 전체 이동을 수행하는 경우에 지원됩니다. 복사 후 보내는 앱에 원본 삭제를 요청하는 일반적인 이동 방식에서는 원본이 남습니다.
- 내장 파일 작업은 같은 이름을 건너뛰며 덮어쓰기·병합을 하지 않습니다. 셸 명령과 외부 드롭 대상은 Windows·확장 프로그램의 정책을 따릅니다.
- 실제 Windows 메뉴 클릭, Explorer·브라우저로의 물리적 드롭, 클립보드 왕복은 수동 검증되지 않았습니다.

- 전체 `npm test`: 59개 통과, 1개 건너뜀, 실패 0개.
- 로컬 `0.5.0-fixed` 빌드 성공. 실제 패키징 앱에서 클립보드 읽기·메뉴 IPC 중첩 충돌을 재현한 뒤 수정 결과를 확인했습니다.
- 위 검증은 실제 메뉴 클릭·물리적 드롭·클립보드 왕복의 수동 검증을 대신하지 않습니다.
