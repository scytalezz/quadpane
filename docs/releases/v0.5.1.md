# Quadpane v0.5.1

Windows x64 포터블 · `0.5.1`

파일: `quadpane-0.5.1-portable-x64.exe`

## 주요 변경

- 한글 `HWP/HWPX/HWT` 파일에 청록색 **한** 아이콘을 표시합니다.
- Word `DOC/DOCX/DOCM/DOT/DOTX/DOTM` 파일에 파란색 **W** 아이콘을 표시합니다.
- PowerPoint `PPT/PPTX/PPTM/PPS/PPSX/PPSM/POT/POTX/POTM`과 `ODP` 파일에 주황색 **P** 아이콘을 표시합니다.
- 스프레드시트 아이콘 분류를 `XLS/XLSX/CSV`에서 `XLSM/XLSB/XLT/XLTX/XLTM/ODS`까지 확대합니다.
- 텍스트 `TXT/MD/RTF/LOG/ODT`를 별도 아이콘으로 구분하고, 이미지 아이콘 분류에 `TIF/TIFF/AVIF`를 추가합니다.
- 미분류 확장자와 확장자 없는 파일에는 중립색 기본 파일 아이콘을 표시합니다.
- 파일 목록의 파일·폴더 아이콘을 **18px → 20px**로 키우고, 새 아이콘에 라이트·다크 테마별 색상을 적용합니다.

사용법은 [포터블 안내](https://github.com/scytalezz/quadpane/blob/v0.5.1/PORTABLE.md)를 참고하세요. 이전 버전의 변경 사항과 검증 기록은 [v0.5.0 릴리스 노트](https://github.com/scytalezz/quadpane/blob/v0.5.0/docs/releases/v0.5.0.md)에 있습니다.
