# Quadpane v0.6.0

Windows x64 포터블 · `0.6.0`

파일: `quadpane-0.6.0-portable-x64.exe`

마우스 입력 수정본: `quadpane-0.6.0-mousefix-portable-x64.exe` (내부 버전 `0.6.0`)

## 마우스 측면 버튼 수정

기존 코드는 Windows 탐색 명령만 처리해, Chromium 화면으로 직접 전달되는 측면 버튼 입력을 놓쳤습니다. 이 경로에서는 폴더가 이동하지 않았으며, 버튼을 누르면 포인터 아래의 다른 패널이 활성화되기도 했습니다.

이제 화면에 전달되기 전 측면 버튼의 누름·뗌을 처리하고, 버튼을 뗄 때 기존 활성 패널을 한 번 이동시킵니다. Windows 탐색 명령 처리도 유지합니다. 이전 실행파일을 완전히 종료한 뒤 수정본을 실행하세요.

## 주요 변경

- 각 패널의 뒤로 가기 버튼 옆에 **앞으로 가기** 버튼을 추가합니다. 해당 방향의 기록이 없거나 폴더를 불러오는 중이면 버튼을 비활성화합니다.
- 마우스 뒤로·앞으로 가기 버튼으로 현재 활성 패널의 방문 기록을 이동합니다. 포인터가 다른 패널 위에 있어도 활성 패널을 기준으로 합니다.
- `Alt+←`와 `Alt+→`로 뒤로·앞으로 이동할 수 있습니다.
- 패널별로 기록을 관리합니다. 뒤로 간 뒤 새 폴더로 이동하면 그 패널의 앞으로 가기 기록을 지우며, 새로고침과 같은 경로 재입력은 기록을 유지합니다.
- 폴더를 읽지 못하면 방문 기록을 유지합니다. **다시 시도**로 성공하면 원래 요청한 뒤로·앞으로 이동을 완료합니다.
- 다른 패널에서 폴더 이름을 바꾸거나 이동하면 뒤로·앞으로 가기 기록에도 변경된 경로를 반영합니다. 탐색 요청과 변경 작업이 겹쳐도 원래 이동 방향을 유지합니다.
- 대화상자, 파일 작업, 셸 메뉴 처리, 폴더 로딩 중에는 마우스 탐색 입력을 무시합니다.

사용법은 [포터블 안내](../../PORTABLE.md), 이전 변경 사항은 [v0.5.1 릴리스 노트](v0.5.1.md)를 참고하세요.

## 검증 (2026-10-01)

- JavaScript 문법 검사 31개 파일 통과.
- 자동 테스트 116개 통과, 다른 드라이브 간 이동 테스트 1개는 환경 조건으로 건너뜀, 실패 0개.
- 이전 Windows 메시지 검사만으로는 화면으로 전달되는 입력 누락을 발견하지 못했습니다. Chromium 측면 버튼 입력 검사를 추가해 수정 전의 실패를 재현했습니다.
- 수정된 패키지에서 Chromium 입력과 Windows 메시지 경로 검사가 모두 통과했습니다. 활성 패널 유지, 버튼을 뗄 때 한 단계 이동, 브라우저 페이지 기록 유지와 기존 탐색 조작을 확인했습니다.
- 포터블 EXE 빌드, 최초 실행, 재실행, EXE와 설정 폴더를 함께 옮긴 뒤 실행 검사가 통과했습니다. 열린 폴더·분할·즐겨찾기·테마가 복원되고 정상 종료됨을 확인했습니다.
- 실제 마우스 하드웨어와 제조사 프로그램의 버튼 재지정은 검사하지 않았습니다.
