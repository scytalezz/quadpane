# Quadpane v0.7.0

Windows x64 포터블 · `0.7.0`

파일: `quadpane-0.7.0-portable-x64.exe` · [GitHub 릴리스](https://github.com/scytalezz/quadpane/releases/tag/v0.7.0)

## v0.5.1 대비 주요 변경

- 각 패널에 **앞으로 가기** 버튼과 `Alt+→`를 추가합니다. 뒤로 가기와 함께 패널별 방문 기록을 이동하며, 해당 방향의 기록이 없거나 폴더를 불러오는 중이면 버튼을 비활성화합니다.
- 마우스 측면 버튼의 뒤로·앞으로 가기 입력을 수정합니다. 버튼을 뗄 때 현재 활성 패널을 한 단계 이동하며, 포인터가 다른 패널 위에 있어도 활성 패널이 바뀌지 않습니다. Windows 탐색 명령을 통한 입력도 계속 지원합니다.
- 뒤로 간 뒤 새 폴더를 열면 해당 패널의 앞으로 가기 기록만 지웁니다. 새로고침과 같은 경로 재입력은 기록을 유지합니다.
- 폴더 읽기에 실패해도 방문 기록을 유지하고, **다시 시도**가 성공하면 원래 요청한 방향으로 이동합니다.
- 다른 패널에서 폴더 이름을 바꾸거나 이동하면 방문 기록의 경로도 갱신합니다. 탐색·재시도와 변경 작업이 겹쳐도 출발 경로와 이동 방향을 유지하고, 완료한 이동을 기록에 중복 반영하지 않습니다.
- 대화상자, 파일 작업, 셸 메뉴 처리, 폴더 로딩 중에는 뒤로·앞으로 가기를 제한합니다. 방문 기록은 앱 실행 중에만 유지됩니다.

## 실행과 설정

기존 Quadpane를 완전히 종료한 뒤 새 EXE를 실행하세요. 기존 `quadpane-data/`를 새 EXE 옆에 그대로 두면 열린 폴더·작업 공간·즐겨찾기·테마를 이어서 사용할 수 있습니다. 설치·관리자 권한·별도 Node.js는 필요하지 않습니다.

사용법은 [포터블 안내](https://github.com/scytalezz/quadpane/blob/v0.7.0/PORTABLE.md)와 [단축키·기능 안내](https://github.com/scytalezz/quadpane/blob/v0.7.0/README.md)를 참고하세요.

## 검증 범위

- 로컬 문법 검사 31개 파일과 자동 테스트 116개가 통과했습니다. 다른 드라이브 간 이동 테스트 1개는 환경 조건으로 건너뛰었습니다.
- GitHub 릴리스는 Windows 환경에서 문법 검사·자동 테스트·포터블 빌드를 통과한 뒤 게시됩니다.
- 실제 마우스 하드웨어와 제조사 프로그램의 버튼 재지정은 검증하지 않았습니다.
