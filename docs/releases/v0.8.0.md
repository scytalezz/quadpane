# Quadpane v0.8.0

Windows x64 포터블 · `0.8.0`

파일: `quadpane-0.8.0-portable-x64.exe` · [GitHub 릴리스](https://github.com/scytalezz/quadpane/releases/tag/v0.8.0)

## v0.7.0 대비 주요 변경

- 도구 모음의 **보기**에서 **숨김 항목**과 **파일 확장자** 표시를 각각 켜거나 끕니다. 기본값은 숨김 항목 끄기·파일 확장자 켜기이며, 모든 패널과 두 작업 공간에 공통 적용하고 재실행 후에도 유지합니다.
- 숨김 여부는 Windows의 Hidden 속성으로 판단합니다. 확장자를 숨겨도 실제 파일명·경로·아이콘·검색·이름 변경 입력은 유지하며, 숨겨진 항목은 전체 선택과 파일 작업 대상에서 제외합니다.
- 목록의 빈 공간이나 양옆 여백에서 드래그하면 사각형 안의 여러 항목을 선택합니다. `Ctrl`·`Shift`로 기존 선택에 추가하고, 목록 가장자리에서 자동 스크롤합니다. `Escape`·포인터 취소·창 포커스 상실 시 이전 선택을 복원합니다. 파일 행에서 시작하는 드래그는 기존 파일 끌어 놓기로 동작합니다.
- 파일 이동이 끝난 뒤 클립보드 완료 알림이 실패해도 실제 이동 결과를 유지하고 양쪽 폴더를 새로 읽습니다. 클립보드 경고는 별도로 표시합니다.
- 상위 폴더와 하위 항목을 함께 복사·이동할 때 중복 처리하지 않습니다. 상위 폴더와 함께 이동된 하위 항목도 클립보드 완료 목록에서 정리합니다.
- 대소문자만 바꾸는 이름 변경에서 중간 이동 응답을 잃으면 원본의 동일성과 대상 존재 여부를 확인합니다. 부분 이동의 원인 코드·남은 경로를 보존하며, 불확실한 결과를 자동 재시도하거나 남은 파일을 임의로 삭제하지 않습니다.

자세한 동작과 제한은 [표시·선택·이동 개선](https://github.com/scytalezz/quadpane/blob/v0.8.0/docs/display-selection.md)을 참고하세요.

## 실행과 업그레이드

기존 Quadpane를 완전히 종료한 뒤 `quadpane-0.8.0-portable-x64.exe`를 쓰기 가능한 폴더에 두고 실행하세요. 기존 `quadpane-data/`를 새 EXE 옆에 그대로 두면 열린 폴더·작업 공간·즐겨찾기·테마를 이어서 사용할 수 있습니다. 기존 표시 설정도 유지하며, 표시 설정이 없으면 새 기본값만 적용합니다. 설치·관리자 권한·별도 Node.js는 필요하지 않습니다.

사용법은 [포터블 안내](https://github.com/scytalezz/quadpane/blob/v0.8.0/PORTABLE.md)와 [단축키·기능 안내](https://github.com/scytalezz/quadpane/blob/v0.8.0/README.md)를 참고하세요.

## 검증 범위

- 로컬 문법 검사 **32개 파일 통과**, 자동 테스트 **145개 통과·실패 0개·건너뜀 0개**. 다른 드라이브 간 파일·폴더 이동 검사도 포함합니다.
- 출시 전 패키징 프리뷰에서 표시·선택·이동 **10개**, 셸 연동 **4개**, 탐색 **9개** 검사 그룹과 포터블 런처 **3회** 실행이 통과했습니다. 상세 기록은 [프리뷰 검증 이력](https://github.com/scytalezz/quadpane/blob/v0.8.0/docs/display-selection.md)에 있습니다.
- 공식 EXE는 Windows CI에서 생성하며 SHA-256 체크섬을 함께 제공합니다. 위 프리뷰 결과는 공식 EXE 실행 검증과 구분합니다.
- 실제 SMB 장애·외장 드라이브 분리, 물리적 셸 메뉴 조작·외부 앱 드롭·클립보드 왕복·마우스별 버튼 재지정은 검증 범위에 포함하지 않습니다. [셸 통합 검증 범위](https://github.com/scytalezz/quadpane/blob/v0.8.0/docs/windows-shell.md)를 참고하세요.
