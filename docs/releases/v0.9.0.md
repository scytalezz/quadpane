# Quadpane v0.9.0

폴더 탐색의 반복 조회와 화면 갱신을 줄이고, 로딩 안내·삭제 확인창·작업표시줄 아이콘을 개선한 Windows x64 포터블 릴리스입니다.

## 탐색 성능

- 폴더 열거에서 이름·크기·수정 시각·숨김 속성을 함께 읽습니다. 일반 탐색에서 파일마다 별도 속성 조회를 실행하지 않습니다.
- 창 없는 조회 도우미 하나를 재사용하고 같은 경로의 동시 요청을 합칩니다. 10초간 사용하지 않으면 도우미를 종료합니다.
- 연결 폴더의 대상 조회도 도우미 안에서 수행해 응답 시간 제한과 종료 처리가 적용됩니다.
- 완료된 파일 목록을 앱 캐시에 저장하지 않습니다. F5와 새로고침 버튼은 핸들로 메타데이터를 재확인해 다른 하드 링크를 통한 수정도 반영합니다. 일반 탐색의 Windows 열거 정보는 이런 변경이 늦게 반영될 수 있습니다.
- 기존 목록을 기다리는 동안 다시 정렬하고 그리던 중복 작업을 제거합니다.

## 사용성 및 오류 수정

- 탐색할 때마다 표시하던 “경로 불러오는 중…” 안내를 없애고 새로고침 아이콘으로 상태를 표시합니다. 실제 읽기 오류와 다시 시도 안내는 유지합니다.
- Delete 키를 누른 상태에서 삭제 확인창을 취소해도 이후 파일 선택 때 다시 열리지 않도록 수정합니다.
- 패널 주소창 옆에 새 폴더·이름 변경·휴지통 아이콘을 추가하고 파일 목록 왼쪽의 드래그 선택 여백을 조금 늘립니다.
- 작업표시줄의 재실행 대상을 원본 포터블 EXE로 고정하고 아이콘을 설정 폴더에 보관합니다. 확인된 잘못된 고정 바로가지만 보정합니다.
- 기존 숨김 항목·확장자 설정, 다중 선택, 마우스 뒤로·앞으로 가기, Windows 셸 메뉴·클립보드·드래그 연동을 유지합니다.

## 업데이트

1. 실행 중인 Quadpane를 종료합니다.
2. `quadpane-0.9.0-portable-x64.exe`를 기존 `quadpane-data` 폴더 옆에 둡니다.
3. 새 EXE를 실행합니다. 기존 작업 공간·즐겨찾기·테마·표시 설정을 그대로 사용합니다.

설치·관리자 권한·별도 Node.js가 필요하지 않습니다. `SHA256SUMS.txt`로 다운로드한 파일의 체크섬을 확인할 수 있습니다.

## 검증 범위

문법 검사 43개 파일과 자동 테스트 266개가 통과했고 실패는 없습니다. 파일 심볼릭 링크 권한·실제 SMB 공유가 필요한 2개 검사는 건너뛰었습니다. 다른 드라이브 사이의 실제 복사·이동, 파일 탐색·마우스 버튼·표시 설정·선택·삭제 취소·로딩 표시·작업표시줄 검사와 실제 포터블 3회 실행을 완료했습니다.

같은 로컬 폴더를 두 번씩 열어 측정한 목록 DOM 갱신 시간은 직전 탐색 프리뷰 대비 파일 10개에서 평균 108ms → 4ms, 1,000개에서 124ms → 37ms였습니다. 압축 해제·화면 그리기·후속 설정 저장·네트워크 공유 시간은 포함하지 않습니다.

자세한 결과와 실제 EXE 검증 기록은 [PORTABLE.md](../../PORTABLE.md#실행-검증)에 있습니다. 물리적 마우스의 제조사별 재지정, 실제 외부 앱 드롭 완료, 모든 SMB 서버·셸 확장 조합을 자동 검사가 보장하지는 않습니다.
