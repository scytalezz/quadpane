# Quadpane v0.9.1

Windows 탐색기·브라우저로 드래그할 때의 취소·오류 복구를 보강하고, 현재 버전 표시와 앱 내 업데이트를 추가한 Windows x64 포터블 릴리스입니다.

## 드래그와 셸 도우미 복구

- 이전 도우미의 실제 종료를 확인한 뒤 다음 도우미를 시작합니다. 종료 신호 전송만으로 정리가 끝났다고 판단하지 않습니다.
- 마우스를 놓은 뒤 드롭이 확정되지 않은 네이티브 호출이 멈추면 취소하고 도우미를 정리합니다. 이 취소를 일반 도우미 충돌 오류와 구분합니다. 이미 확정된 외부 파일 전송에는 시간 제한을 적용하지 않습니다.
- 앱의 정상 종료뿐 아니라 강제 종료도 별도 프로세스 핸들로 감시합니다. 연결이 닫히면 아직 실행하지 않은 요청을 폐기합니다.
- 숨겨진 셸 창의 처리되지 않은 예외가 작업 중 상태를 남기지 않도록 해당 도우미를 종료합니다.
- 파일 검증 중 준비된 도우미가 종료돼도 아직 보내지 않은 요청은 새 도우미에서 시작합니다. 이미 보낸 복사·이동 요청은 자동 재실행하지 않습니다.
- 드래그 중 포커스가 돌아올 때 목록 새로고침이 끼어드는 문제, 대화상자 뒤의 드래그 시작과 취소 뒤 남는 화면 상태를 수정합니다.

## 버전 표시와 업데이트

- 왼쪽 아래의 연결 문구를 현재 버전으로 바꿉니다.
- 실행 후 GitHub의 최신 정식 릴리스를 한 번 확인하고, 버전 버튼에서도 다시 확인할 수 있습니다.
- 새 버전을 다운로드하면 SHA-256을 검증한 뒤 **업데이트하고 다시 시작** 버튼을 제공합니다.
- 파일 작업 중에는 재시작하지 않고, 열린 폴더·작업 공간·표시 설정을 저장한 뒤 새 EXE를 실행합니다. 새 EXE와 기존 EXE는 같은 폴더에 보관하며 `quadpane-data`를 이어서 사용합니다.
- 인터넷 연결은 업데이트 확인·다운로드에만 필요합니다. 오프라인에서도 파일 탐색을 사용할 수 있습니다.

## 설치

v0.9.0까지의 공식 배포본에는 앱 내 업데이트가 없으므로 이번 버전은 직접 내려받아 주세요.

1. 실행 중인 Quadpane를 종료합니다.
2. `quadpane-0.9.1-portable-x64.exe`를 기존 `quadpane-data` 폴더 옆에 둡니다.
3. 새 EXE를 실행합니다. 설정 폴더를 지울 필요는 없습니다.

`SHA256SUMS.txt`로 다운로드한 EXE를 확인할 수 있습니다.

## 검증 범위

로컬 자동 검사에서 355개가 통과했습니다. 다른 드라이브로의 이동 4개 검사는 별도로 실행했으며, 실제 SMB 공유와 파일 심볼릭 링크 권한이 필요한 2개 검사는 건너뛰었습니다. 드래그 화면 복구는 9개 시나리오를 검사했습니다.

도우미 종료와 재시도 경쟁, 드래그 취소·드롭 확정 경쟁, 실제 숨겨진 네이티브 호스트의 예외·부모 강제 종료를 자동 검사합니다. 화면 검사는 격리된 응답과 임시 파일을 사용하며 사용자 마우스·클립보드를 조작하지 않습니다. 실제 Explorer·브라우저의 물리적 드롭과 모든 셸 확장 조합의 호환성을 자동 검사로 보증하지는 않습니다.

상세한 재현 내용은 [셸 복구 기록](../shell-recovery.md)을 참고하세요.
