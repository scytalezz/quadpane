# Quadpane v0.9.2

2026-10-29 · Windows x64 포터블

외부 파일 복사·붙여넣기·드래그가 아무 반응 없이 무시되거나 취소되는 원인을 수정하고, 시작과 작은 파일 작업의 준비 시간을 줄였습니다.

## 외부 파일 작업 안정화

- 탐색기에서 돌아온 뒤 같은 폴더를 새로고침하는 중에도 복사·붙여넣기·드래그를 사용할 수 있습니다. 다른 폴더로 탐색 중일 때는 대상이 확정될 때까지 차단합니다.
- 빠른 복사→붙여넣기, 연속 복사와 늦게 도착한 클립보드 응답의 충돌을 막습니다. 붙여넣기 대상을 먼저 확정하고 중복 실행을 차단합니다.
- 마우스 버튼 해제와 OLE 알림 사이에 최대 250ms의 유예를 둬 정상 드래그가 일찍 취소되는 문제를 수정합니다. 실제 드롭은 OLE 알림으로만 확정하고, 이미 시작한 외부 작업은 보호합니다.
- 일시적인 클립보드 잠금에는 읽기만 제한적으로 재시도합니다. 결과가 불확실한 파일 변경이나 클립보드 쓰기는 자동 재실행하지 않습니다.
- 로컬 경로가 없는 브라우저의 가상 파일 드롭에는 안내를 표시합니다. 웹 이미지·링크 다운로드 기능은 포함하지 않습니다.

내장 복사·이동은 같은 이름을 계속 건너뛰며 덮어쓰거나 폴더를 병합하지 않습니다. 셸 메뉴와 외부 드롭 대상은 Windows·확장 프로그램의 동작을 따릅니다.

## 성능 개선

- 보이는 패널만 조회·렌더링하고, 숨긴 패널과 보조 작업 공간은 열 때 갱신합니다.
- 드라이브 목록은 기존 네이티브 도우미를 재사용하며, 파일별 이동과 복사 후 최종 배치는 작은 전용 도우미로 처리합니다.
- 포터블의 `portable.useZip` 설정으로 압축 해제 비용을 줄입니다. EXE 크기는 늘어나며 종료 후 임시 런타임 정리는 유지합니다.

v0.9.1과 **v0.9.1 기반 출시 전 프리뷰**의 시작 시간 중앙값은 **8.33초 → 4.90초**, EXE 크기는 **약 109 → 158MB**였습니다. 로컬 파일 100개·표시 패널 4개·각 3회·웜 캐시 조건이며, 업데이트 통신과 작업표시줄 복구는 제외했습니다. 최종 v0.9.2 배포본의 측정값이나 속도 보장은 아닙니다. [측정 조건과 프리뷰 해시](https://github.com/scytalezz/quadpane/blob/v0.9.2/docs/transfer-performance.md)는 최종 배포본과 구분해 기록합니다.

## 업데이트

v0.9.1 사용자는 왼쪽 아래 버전 버튼에서 업데이트를 확인한 뒤 **다운로드 → 업데이트하고 다시 시작**을 선택할 수 있습니다. 직접 바꾸려면 앱을 종료하고 `quadpane-0.9.2-portable-x64.exe`를 기존 `quadpane-data` 폴더 옆에 두세요. 설정은 그대로 이어서 사용합니다.

v0.9.0 이하에서는 [GitHub 릴리스](https://github.com/scytalezz/quadpane/releases/tag/v0.9.2)에서 직접 내려받아 주세요. 다운로드한 EXE는 릴리스의 `SHA256SUMS.txt`로 확인합니다.

## 검증 범위

- JavaScript 52개 파일 문법 검사, 전체 단위 테스트 **365개 통과·환경 조건 2개 건너뜀**, 네이티브 도우미 3개와 포터블 빌드가 통과했습니다. 별도 볼륨 이동 4개는 통과 수에 포함하며, 건너뛴 항목은 파일 심볼릭 링크 권한·선택적 SMB 공유 조건입니다.
- 렌더러 경합 시나리오 **24개**, 드래그 복구 **9개 그룹**이 통과했습니다. 로컬 v0.9.2 EXE도 최초 실행·재실행·이동 후 실행 **3회**에서 버전 표시와 설정 복원을 확인했습니다. GitHub에서 생성한 배포본은 별도 체크섬을 제공합니다.
- 실제 Explorer·브라우저로 물리적 마우스 드롭은 수행하지 않았습니다. 모든 외부 앱·셸 확장 조합의 호환성을 보장하지 않습니다.

상세한 수정 원인과 검증 한계는 [외부 파일 작업·시작 성능 개선 기록](https://github.com/scytalezz/quadpane/blob/v0.9.2/docs/transfer-performance.md)에 있습니다.
