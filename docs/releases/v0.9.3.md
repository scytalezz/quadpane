# Quadpane v0.9.3

2026-11-04 · Windows x64 포터블

외부 드래그의 완료 응답이 끊겼을 때 남는 대기 상태를 정리하고, 화면에서 취소·복구할 수 있도록 개선합니다.

## 드래그 대기와 취소 개선

- 네이티브 도우미의 응답 통로가 닫히거나 오류가 나면 프로세스 종료 알림만 기다리지 않고 요청을 정리합니다. 줄 단위 응답 처리(`readline`)에서 전달되는 오류도 처리해 처리되지 않은 예외로 앱이 종료되는 문제를 막습니다. 도우미의 실제 종료가 확인될 때까지 추적을 유지합니다.
- 드롭 승인 전 진행 보고가 막혀도 버튼 해제 감시가 작동합니다. 늦게 돌아온 보고가 취소된 드래그를 다시 승인하지 않으며, 새 마우스 누름도 취소된 요청의 정리를 늦추지 않습니다.
- 상태줄에 **드래그 취소** 버튼을 표시하고, 응답 단절이나 셸 사용 중 오류 뒤에는 **Windows 작업 복구** 버튼을 유지합니다. 버튼과 `Esc`로 같은 취소 동작을 요청할 수 있습니다. 원래 드래그 응답을 받기 전에는 중복 드래그를 허용하지 않으며, 앱 내부 복사·이동 중에는 복구 버튼을 비활성화합니다.

이미 시작한 외부 파일 전송에 자동 제한 시간을 추가하지 않습니다. 응답이 끊겼다는 이유만으로 승인된 전송의 도우미를 강제 종료하지 않으며, 결과가 불확실한 복사·이동·드롭을 자동 재실행하지 않습니다. 복구는 파일 전송을 되돌리는 기능이 아니므로 원본·대상 상태를 확인한 뒤 다음 작업을 진행하세요.

## 업데이트

v0.9.1 이상에서는 왼쪽 아래 버전 버튼으로 업데이트를 확인할 수 있습니다. 직접 교체하려면 앱을 완전히 종료하고 `quadpane-0.9.3-portable-x64.exe`를 기존 `quadpane-data` 폴더 옆에 두세요. 설정은 그대로 이어서 사용합니다.

[GitHub 릴리스](https://github.com/scytalezz/quadpane/releases/tag/v0.9.3)에 첨부된 `SHA256SUMS.txt`로 다운로드한 파일을 확인합니다.

## 검증 범위

- v0.9.3 로컬 검사: JavaScript **52개 파일** 문법 검사, 단위 테스트 **389개 통과·선택적 환경 조건 2개 건너뜀**. 다른 볼륨 이동 검사를 활성화한 결과입니다. 로컬 포터블 EXE 빌드와 소스·버전 일치 확인도 완료했습니다.
- 앞선 수정 소스·프리뷰 검사: 드래그 **12개**, 전송 경합 **24개** 통과. 패키징 검사 **7개 그룹**과 `0.9.2-dragfix` 프리뷰 실행 **3회**도 통과했습니다.
- 로컬 **v0.9.3 런처 3회 실행**에서 정상 종료·설정 복원·임시 런타임 정리와 버전 표시를 확인했습니다. 실행 기록은 `.checks/release-093-launcher.log`에 있습니다. GitHub 배포본의 체크섬은 릴리스에 첨부된 파일을 기준으로 확인합니다.
- 보고된 실제 Explorer·브라우저의 물리적 드래그 장애는 재현하지 못했습니다. 제어된 응답 단절·보고 정지·취소 경합 검사는 해당 장애의 최초 원인이나 모든 외부 앱·셸 확장과의 호환성을 확정하지 않습니다.

수정 원인과 검증 한계는 [셸 메뉴·드래그 복구 기록](https://github.com/scytalezz/quadpane/blob/v0.9.3/docs/shell-recovery.md)에 있습니다.
