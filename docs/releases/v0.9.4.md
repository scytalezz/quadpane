# Quadpane v0.9.4

2026-11-06 · Windows x64 포터블

외부 파일 드롭과 Windows 작업 복구의 경합 처리를 보강하고, 정렬·검색·선택과 파일 작업의 불필요한 처리를 줄입니다.

## 외부 드롭과 복구

- 드래그 도우미의 정상 응답 스트림 종료와 실제 통신 오류를 구분합니다. 깨끗한 EOF 뒤 최대 100ms 동안 종료 코드를 기다려 드롭 승인 전 감시 종료 코드 2를 취소로 처리합니다. 종료가 확인되지 않으면 연결 오류를 알립니다.
- 복구 성공을 해당 드래그·메뉴 요청에 연결해, 같은 요청의 늦은 오류가 복구 대기를 다시 켜지 않도록 합니다. 다른 요청의 오류와 복구 실패는 유지하며, 복구 중이거나 복구가 필요한 상태에서는 드롭을 거부합니다.
- 이전 네이티브 드래그와 경로가 다른 외부 파일을 내부 이동으로 처리하지 않습니다. 외부 파일 드롭의 OLE 응답은 COPY로 고정해 비동기 파일 처리 완료 전에 외부 앱이 원본을 삭제하지 않도록 합니다.
- 이동 도우미 시작 후 프로세스·통신 오류가 발생해도 실제 종료까지 작업 예약을 유지해 중복 이동을 막습니다. 파일 처리와 클립보드 후처리가 끝나면 전체 예약을 해제하고 목록 갱신은 패널별로 처리합니다. 다른 경로로 탐색 중인 패널의 드롭 차단은 유지합니다.

이미 시작한 파일 변경을 시간 경과만으로 취소했다고 간주하거나, 결과가 불확실한 복사·이동·드롭을 자동 재실행하지 않습니다. 복구는 파일 작업을 되돌리는 기능이 아니므로 원본·대상 상태를 확인한 뒤 다음 작업을 진행하세요.

## 앞선 최적화 반영

- 동일한 목록의 정렬 결과와 한국어 비교기를 재사용하고, 검색 후 선택 갱신과 변하지 않은 행의 접근성 속성 쓰기를 줄입니다. 파일 시스템 조회 결과 자체는 캐시하지 않습니다.
- 새로고침 대기 중 바꾸거나 해제한 선택을 응답 완료 시점에도 보존합니다.
- 대상 이름 충돌을 원본 하위 트리 검사보다 먼저 확인해 불필요한 조회를 줄입니다. 최종 파일 게시 단계의 덮어쓰기 방지는 유지합니다.
- 작업 공간 설정 저장에 고유한 임시 파일을 배타적으로 생성합니다. 기존 임시 파일에 연결된 파일을 덮어쓰거나, 생성에 실패한 파일을 정리 대상으로 삭제하지 않습니다.

최적화 계측은 정렬·조회·속성 쓰기 횟수의 감소를 확인한 것으로, 실제 화면 속도나 시작 시간의 개선 배율을 뜻하지 않습니다.

## 업데이트

배포 후 v0.9.1 이상에서는 왼쪽 아래 버전 버튼으로 업데이트를 확인할 수 있습니다. 직접 교체하려면 앱을 완전히 종료하고 `quadpane-0.9.4-portable-x64.exe`를 기존 `quadpane-data` 폴더 옆에 두세요. 설정은 이어서 사용합니다. 다운로드한 파일은 [GitHub 릴리스](https://github.com/scytalezz/quadpane/releases/tag/v0.9.4)의 `SHA256SUMS.txt`를 기준으로 확인합니다.

## 검증 범위

- v0.9.4 로컬 구문 검사 **53개 파일**, 전체 Node 테스트 **409개 통과·2개 건너뜀**, 실패 없음. 별도 드라이브의 복사·이동 검사도 포함합니다.
- v0.9.4 포터블 EXE 빌드와 **3회 실행** 검사 통과. 한글 경로 실행·EXE와 프로필 이동 후 재실행에서 버전 표시·테스트 폴더 읽기·설정 유지·정상 종료·임시 런타임 정리를 확인했습니다. 패키지의 수정 소스가 검증한 작업 트리와 일치합니다. GitHub 배포본의 체크섬은 릴리스 첨부 파일을 기준으로 확인합니다.
- 헤드리스 브라우저 전송 경합 **37개**·드래그 복구 **13개** 검사 묶음, 렌더러 최적화 회귀 검사 **9개** 통과.
- 숨김 Electron 창의 renderer/preload/main 통합 **8개** 검사 묶음 통과. 복사·이동·이름 변경은 격리된 실제 파일로 확인하며 시스템 클립보드와 셸 호출은 대체 응답을 사용합니다.
- 위 화면·전송 검사는 버전 변경 전 동일한 수정 소스와 프리뷰에서 수행한 기록입니다. 릴리스 준비 중 실행 코드가 바뀌지 않았음을 확인했습니다.

실제 Windows 탐색기의 물리적 드래그에서 보고된 간헐적 실패가 모두 해결됐는지는 아직 확인하지 못했습니다. 자동화된 지연·통신 오류 재현은 원래 사용 환경의 재현이나 모든 외부 앱·셸 확장과의 호환성을 확정하지 않습니다.

상세 근거와 프리뷰 식별값은 [외부 파일 드래그 및 복구 점검](https://github.com/scytalezz/quadpane/blob/v0.9.4/docs/incoming-drag-review.md), 최적화 측정과 이전 검증은 [소스 검토 및 최적화](https://github.com/scytalezz/quadpane/blob/v0.9.4/docs/optimization-review.md)에 있습니다.
